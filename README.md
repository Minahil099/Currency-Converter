# 💱 Currency Converter

A simple and modern **Currency Converter Web App** built with **HTML, CSS, and JavaScript**.

Convert currencies instantly using exchange rates from a currency API. 🌍

## ✨ Features

- 💰 Convert between multiple currencies
- 🔄 Live exchange rates
- 🚩 Automatic currency flags
- ⚡ Instant conversion
- 📱 Responsive and clean UI
- 🎨 Modern black & blue design

## 🛠️ Technologies

- 🌐 HTML5
- 🎨 CSS3
- ⚙️ JavaScript
- 🔌 Currency Exchange API
- 🚩 Flags API

## 🚀 How It Works

1. 💵 Enter an amount
2. 🌍 Select the **From** currency
3. 🌎 Select the **To** currency
4. 🔘 Click **Get Exchange Rate**
5. ⚡ View the converted amount
